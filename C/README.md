## 📌 Sobre o Módulo

Este diretório contém todo o progresso no ecossistema da **linguagem C**. O foco desta etapa foi aprofundar os conhecimentos em manipulação direta de memória, estruturas de controlo de alta performance, manipulação de arrays e apontadores, além do desenvolvimento de aplicações em consola interativas.

Tópicos centrais desenvolvidos:
- **Fundamentos**: Entrada/saída formatada (`printf`, `scanf`), tipagem estática e operadores binários/lógicos.
- **Estruturas de Controlo**: Tomadas de decisão (`if/else`, `switch/case`) e laços de iteração (`for`, `while`, `do-while`).
- **Coleções**: Vetores unidimensionais, matrizes bidimensionais e strings (`char[]`).
- **Modularização**: Assinatura de funções, protótipos, passagem de parâmetros e escopo.
- **Projetos Complexos**: Jogos de consola interativos, chatbots e simuladores.

## 🛠️ Como Compilar e Executar

Utilizando o compilador **GCC** (via terminal ou MSYS2/MinGW):

```bash
# Compilar um exercício individual
gcc "01 - Ficha 1/Ex1.c" -o Ex1

# Executar no Windows
./Ex1.exe

# Compilar um projeto com otimização
gcc -O2 "06 - Especiais/Chatbot.c" -o Chatbot
./Chatbot.exe
```
