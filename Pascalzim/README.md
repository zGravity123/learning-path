## About the Module

This directory documents the complete learning path in **Pascal (Pascalzim)**, covering algorithmic foundations, modular code architecture, multi-dimensional matrices, and data persistence using text files.

Exercises are organized chronologically and thematically according to curriculum modules (TGPSI):

- **Module 1 & Fundamentals**: Variables, primitive types, arithmetic expressions, and conditional branches (`if/else`, `case`).
- **Module 2**: Iteration and loop constructs (`for`, `while`, `repeat...until`).
- **Module 3**: Procedural programming and subroutines using **Procedures** (`procedure`) and **Functions** (`function`).
- **Module 4**: Linear and multidimensional data structures - **Vectors** (1D arrays) and **Matrices** (2D arrays).
- **Module 5**: File input/output streams (`assign`, `reset`, `rewrite`, `append`), text persistence, and capstone software project.

## Project Highlights

### Tic-Tac-Toe ([`13 - Especiais/jogodogalo.pas`](./13%20-%20Especiais/jogodogalo.pas))
An interactive console-based game featuring:
- Dynamic terminal grid rendering
- Real-time move validation and win/tie condition checks
- Match history tracking persisted to a text file

### Escape Room ([`13 - Especiais/scaperoom.pas`](./13%20-%20Especiais/scaperoom.pas))
A text adventure game with puzzle mechanics, password decoding, and multi-room progression.

### Capstone Project - School Management System ([`11 - M5 (Fichas)/04 - Projeto Final`](./11%20-%20M5%20(Fichas)/04%20-%20Projeto%20Final))
A complete academic management software with persistent storage:
- Student record management (`alunos.txt`)
- Course and subject records (`disciplinas.txt`)
- Grade registration and lookup (`notas.txt`)
- Automated GPA/average calculations and report generation

## How to Run

To run any program from this module:
1. Open the `.pas` file in **Pascalzim** (or Free Pascal / Lazarus).
2. Press `F9` (or click **Execute**) to compile and launch in the terminal.
3. Ensure required `.txt` data files (where applicable) reside in the same folder as the source code.
